User Guide

Everything you need to annotate and translate CSV datasets with EdgeLabel.

Quick start — Annotation

  1. 1.Open annotation.html and click Get Started.
  2. 2.Drag a CSV file onto the upload zone, or click to browse. The file is read locally — nothing is uploaded.
  3. 3.Click Settings and select the column containing the text you want to annotate. Click Save.
  4. 4.Click a label button, or press the number key shown (1–9). The row is saved and you advance automatically.
  5. 5.When finished, click ↓ CSV, ↓ JSON, or ↓ JSONL to download your annotated dataset.

Export formats

CSV

Three columns: Data, Label, Comment. Only annotated rows are exported. RFC 4180 compliant — safe to open in Excel, Google Sheets, pandas.

JSON

Array of objects: [{"data":"…","label":"…","comment":null}]. Useful for programmatic post-processing.

JSONL new

One JSON object per line — the standard format for LLM fine-tuning datasets (OpenAI, Anthropic, Mistral, Llama). Import directly into your training pipeline.

Translation CSV

Your original CSV with two new columns appended: Translation and Comment. All original rows preserved.

CSV file requirements

  • ✓ UTF-8 encoding (most text editors and spreadsheet apps use this by default)
  • ✓ First row is the header row (column names)
  • ✓ Comma-delimited; quoted fields with embedded commas or newlines are supported
  • ✓ Any number of columns; you select which one to annotate or translate
  • ⚠ Very large files (>50,000 rows) may slow down the browser — split them into batches

Browser support

EdgeLabel works in any modern browser that supports ES modules and the File API:

  • ✓ Chrome 90+
  • ✓ Firefox 90+
  • ✓ Safari 15+
  • ✓ Edge 90+

Internet Explorer is not supported.

FAQ

Is my data safe?

Yes. Files are read by your browser's File API and never transmitted anywhere. All processing is in-memory, on your device.

What happens if I close the browser tab?

Use Save (or Ctrl+S) regularly. The session is saved to localStorage and can be reloaded from the same browser. If you don't save, unsaved progress is lost on close.

Can I add my own labels?

Yes — open Settings and add or remove labels before or during annotation. The default labels (Positive, Neutral, Negative, Others) can all be removed.

Can I annotate the same file on multiple devices?

Not automatically — sessions are stored locally in each browser. Export your CSV after each session and reimport on the other device to continue.
