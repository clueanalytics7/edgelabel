Regulatory Standard Mapping

HIPAA

Protected Health Information (PHI) Safe Harbor

Under 45 CFR § 164.312, PHI must be protected against unauthorized transmission. Because EdgeLabel never ingests datasets into a remote cloud, healthcare providers and clinical researchers do not need to execute a third-party Business Associate Agreement (BAA). Clinical records remain strictly on the hospital or researcher's workstation.

GDPR

Articles 5, 28, and 32 Data Minimization

Eliminates cross-border data transfer liabilities (Schrems II). As no personal data is transferred across international boundaries or stored by third parties, compliance overhead is reduced by design.

SOC 2 & ISO 27001

Auditable Traceability Logs

EdgeLabel includes a client-side cryptographic Audit Trail logger. Every labeling action, schema configuration update, and adjudication decision is hashed with a timestamp and reviewer ID, exportable as an immutable JSON audit log for regulatory review.

Deployment Guidance for Enterprise Teams

EdgeLabel can be hosted on your internal Kubernetes cluster, Nginx intranet gateway, or copied onto an air-gapped secure flash drive:

# 1. Clone repository in your secure enclave
git clone https://github.com/clueanalytics7/edgelabel.git

# 2. Build completely self-contained static assets
npm install && npm run build

# 3. Serve via your internal web server or Docker container
docker run -d -p 8080:80 -v $(pwd)/dist:/usr/share/nginx/html nginx:alpine
