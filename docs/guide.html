User Guide

Everything you need to annotate and translate CSV datasets with EdgeLabel.

Quick start — Annotation

  1. 1
    Open the annotation tool and click Get Started.
  2. 2
    Drag a CSV file onto the upload zone, or click to browse. The file is read locally — nothing is uploaded.
  3. 3
    Click Settings and select the column containing the text you want to annotate. Click Save settings.
  4. 4
    Click a label button, or press the number key shown (1–9). The row is saved and you advance automatically.
  5. 5
    When finished, click Export Dataset to export in fine-tuning formats (OpenAI ChatML, Gemini, Alpaca, Hugging Face) or standard CSV/JSON.
New Feature

Quick start — EdgeVision (Computer Vision)

  1. 1
    Open EdgeVision. You can use the built-in sample images or click Upload Images.
  2. 2
    Choose an active class from the category palette (e.g. Person, Vehicle, Sign) or press 1–9.
  3. 3
    Click and drag directly on the image to draw bounding box rectangles. Drag inside a box to move it, or drag corner handles to resize.
  4. 4
    Switch to Rapid Classification mode when you need to triage whole image categories at high speed with keyboard shortcuts.
  5. 5
    Click YOLO (.zip) to download your normalized YOLO txt files and dataset.yaml, or COCO (.json) for object detection frameworks.

Export formats

CSV

Three columns: Data, Label, Comment. RFC 4180 compliant. Opens in Excel, Google Sheets, pandas.

JSON

Array of objects: {"data","label","comment"}. For programmatic use.

JSONL

LLM

One JSON object per line. Standard fine-tuning format for OpenAI, Anthropic, Mistral, Llama.

Translation CSV

Original CSV with Translation and Comment columns appended. All original rows preserved.

FAQ

Is my data safe?

Yes. Files are read by the browser's File API and never transmitted anywhere. All processing is on your device.

What happens if I close the tab?

Use Save (or Ctrl+S) regularly. The session is saved to localStorage and can be reloaded from the same browser. Unsaved progress is lost on close.

Can I add custom labels?

Yes — open Settings and add or remove labels at any time. Default labels (Positive, Neutral, Negative, Others) can all be changed.

What CSV files are supported?

UTF-8 encoded, comma-delimited CSVs with a header row. Quoted fields with embedded commas are supported. Files over 50,000 rows may slow the browser — split into batches.
