Feature 1

Issues signed cryptographically verifiable JSON packages to onboard paying teams, clinical sites, and research groups.

HMAC-SHA256 Token

Workflow & Lifecycle

Feature 2

Cryptographic Regulatory Audit Trail Verifier

Validates non-repudiation, chronological sequencing, and zero-tampering for FDA 21 CFR Part 11, HIPAA, and GDPR filings.

Web Crypto SHA-256

Verification Engine Mechanics

  1. Local Action Logging: As annotators work in EdgeLabel, every button press, NER character offset selection, undo, or redo is recorded with monotonic timestamps in browser memory.
  2. Auditor Ingestion: The auditor or administrator drags the exported audit_trail_*.json file onto the verifier.
  3. SubtleCrypto Hash: Browser computes an authoritative SHA-256 hash across the raw byte sequence.
  4. Integrity Check: Verifies monotonic timestamps and absence of retroactive event modification.
  5. Compliance Certificate: Emits an instant validation badge ready for submission to regulatory inspectors.

Audit Event Schema Structure

event: "ASSIGN_LABEL"
rowIndex: 42
label: "Pneumonia"
timestamp: "2026-10-28T14:10:05.112Z"
annotatorId: "clinician_03"
sessionId: "sess_89f02a3"

Guarantees complete traceability without storing sensitive patient health information on external cloud databases.

Feature 4

Multi-Annotator Blinded Assignment & Cohen's Kappa

Enforces scientific rigor by partitioning datasets into randomized blinded batches with controlled overlapping control sets.

IAA Adjudication

Blinded Partitioning Flow

  1. Master Dataset Loading: Manager loads a unlabelled CSV (e.g. 1,000 rows).
  2. Overlap Ratio Selection: Manager defines the control overlap ratio (typically 20%).
  3. Deterministic Split: Engine isolates 200 rows as shared control items, then partitions the remaining 800 rows equally between Annotator A and Annotator B.
  4. Subsets Distributed: Two separate CSV files are generated and given to raters with row IDs preserved for automated alignment.

Adjudication & Kappa Scoring

Once both raters complete their work, the two CSVs are loaded into EdgeLabel's IAA Engine. The algorithm automatically aligns corresponding rows, computes observed agreement $P_o$ vs chance agreement $P_e$, and displays the final Cohen's Kappa ($\kappa$):

κ > 0.81: Almost Perfect Agreement
0.61 ≤ κ ≤ 0.80: Substantial Agreement (Clinical Quality)
κ < 0.60: Requires Adjudication Review

Team Taxonomy & Codebook Governance

Standardises class definitions, hotkeys, colour codes, and guidelines across distributed annotators.

Consistency Enforcement

The Codebook feature allows the team lead to create an authoritative taxonomy with detailed guidelines, hotkey shortcuts (1-9), and colour palettes, then export taxonomy_codebook.json for instant rater synchronisation.
